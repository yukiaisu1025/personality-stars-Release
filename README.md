## GitHub Pages で公開する方法

1. GitHub で新しいリポジトリを作成します（例：`personality-stars`）。**Public** にしてください。
2. このフォルダの中身（すべてのファイル。フォルダはありません）を、リポジトリの**一番上（ルート）**にアップロードします。
   - ブラウザの場合：リポジトリ画面の「Add file」→「Upload files」にファイルとフォルダをドラッグ＆ドロップ →「Commit changes」
3. リポジトリの「Settings」→ 左メニュー「Pages」を開きます。
4. 「Build and deployment」の Source を **Deploy from a branch** にし、Branch を **main** / **/(root)** にして「Save」。
5. 1〜2分待つと `https://<ユーザー名>.github.io/personality-stars/` でプレイできます。

> `.nojekyll` は GitHub Pages の自動変換を止めるためのファイルです。消さないでください（見えない場合は「隠しファイルを表示」にしてください）。

### 手元で試す

`index.html` をダブルクリックしても動きます。うまく動かない場合は、フォルダで次のコマンドを実行して `http://localhost:8000` を開いてください。

```
python -m http.server 8000
```

## 調整・追加のヒント

- **人格のステータス・スキル**：`js/data.js` の `D.PERS` と `D.SKILLS`
- **レベルアップの上昇量**：`D.LVUP`（HP+1500/攻撃+500/防御+250、1%で+1750/+550/+320）
- **必要経験値・獲得経験値**：`D.expNeed` / `D.expGain`
- **敵・ボスの強さや攻撃パターン**：`D.ENEMIES`（`hpK`・`atkK`・`defK` が倍率、`atk` が攻撃リスト）
- **武器**：`D.WEAPONS`、ショップの品ぞろえは `D.NPCS` の `shop`
- **ガチャなどの追加機能**：`js/ui.js` の `UI.pauseMenu` にボタンを1つ足し、新しいパネルを `UI.panel()` で作ると、ほかの画面と同じデザインになります。武器の追加は `G.addWeapon(id)` を呼ぶだけです
- **仲間・サポートモンスター**：`D.COMPANIONS`・`D.SUPPORT`・`D.COMPAT`（フワリンの相性）
- **正直者の制限時間**：`D.HONEST`（ミッション600秒・遺跡の基本時間など）
- **お知らせ**：`D.NEWS` の先頭に新しいバージョンを追加すると、タイトルとメニューに NEW が表示されます
- **島の形・地方の位置**：`js/world.js` の `W.REG`・`W.VILLAGES`・`W.DUNGEONS`（シード値は `main.js` の `SEED`）

## 動作環境

WebGL2 対応ブラウザ（Chrome / Edge / Firefox / Safari の最新版）。  
重いと感じたら「設定 → グラフィック」でプリセットを「中」か「低」に、または描画距離・影・草の密度を下げてください。スマホでは自動的に「中」から始まります。
